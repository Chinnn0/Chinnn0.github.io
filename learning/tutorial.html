01

VERSION CONTROL

Git 與 GitHub

Git 是版本控制工具，能在本機記錄檔案修改、比較版本與管理分支。GitHub 是託管 Git 儲存庫的服務，提供遠端備份、協作和 GitHub Pages 等功能。執行 git commit 只建立本機版本；執行 git push 才把提交傳到遠端。

從第一個版本到功能分支

以下指令在練習資料夾內執行。建立檔案的步驟可使用文字編輯器完成；身分設定只作用於這個儲存庫，請填入自己的 GitHub 使用者名稱及 GitHub 提供的 noreply 電子郵件。

git init -b main
git config user.name "你的 GitHub 使用者名稱"
git config user.email "你的 GitHub noreply 電子郵件"

# 使用編輯器新增 README.md 並儲存
git status
git add README.md
git commit -m "Add project introduction"
git log --oneline

# 建立並切換至 feature-notes 分支
git switch -c feature-notes
# 修改 README.md，加入一段學習筆記後儲存
git add README.md
git commit -m "Add learning notes"
git switch main
git merge feature-notes
git log --oneline --graph --all
git status

預期結果：可以看到兩次提交；合併後 main 包含新增的學習筆記，最後的工作目錄沒有尚未提交的修改。提交雜湊與分支顯示依實際操作而不同。

連接 GitHub 並推送

在 GitHub 建立空的遠端儲存庫後，把下面的遠端網址換成實際網址。若 origin 已存在，先使用 git remote -v 檢查，不要重複新增。登入與權限驗證依自己的帳號設定進行。

git remote add origin https://github.com/你的帳號/你的儲存庫.git
git remote -v
git push -u origin main

git add 把目前的修改放入暫存區；git commit 把暫存區內容記為一個版本；git log 檢查提交紀錄。不要把密碼、權杖或私鑰加入版本庫。

小練習：commit 後又修改 README，遠端會自動更新嗎？

不會。新的檔案修改尚未進入上一筆提交。需要再執行 git add README.md、git commit -m "Update README"，最後 git push。可用 git status 與 git log --oneline 檢查。

02

STRUCTURE & SEMANTICS

HTML5 組織內容

HTML 使用標籤描述內容的意義。個人網站可用 header 放頁首、nav 放導覽、main 放主要內容，並以 section 與 article 組織主題和作品。標題應依內容層級排列。

<section aria-labelledby="works-title">
  <h2 id="works-title">我的作品</h2>
  <label for="search">搜尋作品</label>
  <input id="search" type="search" placeholder="輸入作品名稱">
  <article>
    <h3>個人網頁</h3>
    <p>使用 HTML5 和 CSS 建立的頁面。</p>
  </article>
</section>

小練習：如何讓點擊「搜尋作品」文字也能聚焦輸入欄位？

讓 <label for="search"> 的 for 值與 <input id="search"> 的 id 相同。表單控制項仍應有清楚的可見標籤，不能只依賴 placeholder。

LAYOUT & RESPONSIVENESS

CSS 與響應式排版

CSS 透過選擇器指定樣式。.project-card 選取 class，#preview-title 選取 id。盒模型包含內容、padding、border 與 margin；box-sizing: border-box 讓指定寬度包含 padding 與 border，便於控制版面。

* { box-sizing: border-box; }
.projects {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
}
.project-card { padding: 1rem; border: 1px solid #cbd5df; }
@media (max-width: 700px) {
  .projects { grid-template-columns: 1fr; }
}

04

STRUCTURED DATA

JSON 儲存作品資料

JSON 是文字資料格式，可表示物件、陣列、字串、數字、布林值與 null。物件的鍵與字串必須使用雙引號，不能加註解或尾端逗號，也不能直接存函式。JSON.parse() 把 JSON 文字轉成 JavaScript 資料；JSON.stringify() 做反方向的轉換。

{
  "title": "個人網頁",
  "category": "web",
  "tags": ["HTML5", "CSS", "jQuery"],
  "published": true
}

小練習：{ 'title': '作品', } 哪裡不符合 JSON？

鍵與字串使用了單引號，且最後一個欄位後多了逗號。正確寫法是 {"title":"作品"}。

05

ASYNCHRONOUS REQUESTS

Ajax 非同步讀取資料

Ajax 是在背景發送 HTTP 請求、收到回應後更新部分畫面的做法，不是另一種程式語言。名稱雖包含 XML，實務上也能傳送或接收 JSON。非同步表示請求開始後，頁面不必等待回應才處理其他操作；結果要在成功或失敗的回呼中使用。

$.getJSON('../data/projects.json')
  .done(function (data) {
    // 資料抵達後，在這裡更新畫面
  })
  .fail(function () {
    // 顯示錯誤並提供重試
  });

    小練習：為什麼不能在 $.getJSON 下一行就假設 data 已取得？

    請求完成的時間不固定，下一行通常會先執行。應在 .done(function(data) {...}) 內處理資料，並在 .fail() 處理找不到檔案、網路或解析錯誤。

    EVENTS & DOM

    jQuery 選取元素與處理事件

    jQuery 是 JavaScript 函式庫，$('.card') 選取 class 為 card 的元素，.on('click', ...) 綁定點擊事件，.text() 更新文字，.slideToggle() 展開或收合內容。要使用 Ajax，需載入包含 Ajax 的完整版本；slim 版本不包含 Ajax。

    $('#toggle-note').on('click', function () {
  const expanded = $(this).attr('aria-expanded') === 'true';
  $(this).attr('aria-expanded', String(!expanded));
  $('#jquery-note').stop(true, true).slideToggle(150);
});

// 顯示輸入值時使用 text，避免把文字當成 HTML 執行
$('#result').text(userInput);

    回到個人網站檢查

    1. 用 Git 確認網站檔案已提交，並在 GitHub 檢查遠端內容。
    2. 檢查 HTML 標題、導覽、圖片替代文字與輸入欄位標籤。
    3. 縮小視窗，觀察 CSS 是否調整欄數、文字與按鈕是否超出。
    4. 打開 JSON，檢查作品欄位與語法。
    5. 重新讀取作品資料，檢查載入成功與錯誤提示。
    6. 操作 jQuery 搜尋、分類與展開，確認畫面符合預期。
